# Viv Live Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir o pipeline de voz em cascata da Viv por uma sessão Gemini Live em tempo real, com ativação por palmas, nome, atalho e botão, portão de segurança para ações perigosas e uma HUD animada com pop-ups.

**Architecture:** Um pacote `viv/` novo com módulos pequenos: `audio` (dois streams fixos), `wake` (detectores enquanto dorme), `live` (sessão e máquina de estados), `safety` (biometria + confirmação), `tools/` (ferramentas do PC adaptadas). O FastAPI serve a HUD e repassa eventos de um barramento por WebSocket. O código antigo vai para `_legado/`.

**Tech Stack:** Python 3.12, google-genai (Live API), sounddevice, numpy, faster-whisper (`tiny`), resemblyzer, keyboard, FastAPI/uvicorn, pyautogui, Playwright, pytest; HUD em HTML/CSS/JS puros com canvas.

**Spec:** `docs/superpowers/specs/2026-11-12-viv-live-design.md`

## Global Constraints

- Nunca ler, imprimir nem copiar `.env`. A chave é carregada só por `load_dotenv()` em tempo de execução.
- Não tocar em `data/`, `teste_voz.py`, `teste_viv.mp3`, `AGENTS.md`. `VIV_PENDENCIAS.md` só é alterado pelo próprio programa.
- Nada do código antigo é apagado: tudo vai para `_legado/` com `git mv` (ou `mv` se não rastreado).
- Os venvs antigos (`.venv_antes_da_recuperacao`, `.venv_python313`) saem só do índice do git; do disco, apenas com autorização do usuário.
- Commits só com autorização do usuário (regra do `AGENTS.md`). Os passos "Commit" abaixo valem se a autorização cobrir as tarefas; sem ela, deixar as mudanças no working tree.
- Commits sempre com caminhos explícitos (`git commit -- <caminhos>`): o índice tem milhares de arquivos staged que não devem entrar.
- Python 3.12; todos os comandos usam `.venv/Scripts/python.exe`.
- Textos voltados ao usuário (HUD, erros, fala) em português brasileiro. A persona Viv é feminina.
- Nomes de ferramentas usam `_` (ex.: `system_power`), nunca `.`.
- Valores fixados pela spec: áudio de entrada 16 kHz mono int16 em quadros de 20 ms; saída 24 kHz mono int16; inatividade 60 s; confirmação expira em 30 s; buffer biométrico de 6 s; limiar biométrico privilegiado 0,82; palmas entre 120 e 700 ms; trecho de nome até 3 s; atalho `ctrl+alt+v`; servidor em `127.0.0.1:8765`.
- Testes rodam sem rede, sem microfone e sem chave.

## Review Focus

1. **Microfone configurado não existe neste PC** (config veio de outra máquina): usar o dispositivo padrão e informar na HUD, sem derrubar o programa. Teste na Tarefa 5.

5. **Chave ausente ou inválida**: mensagem clara em português na HUD e no terminal, estado `error`, sem laço de reconexão infinito. Teste na Tarefa 7.

### Task 4: Segurança (biometria + confirmação)

**Files:**
- Create: `viv/speaker.py`, `viv/safety.py`, `scripts/enroll_voice.py`
- Test: `tests/test_safety.py`

**Interfaces:**
- Consumes: `registry.call`, `registry.is_dangerous`, `Context`, `Audit`, `BUS`.
- Produces:

```python
class Speaker:
    def __init__(self, cfg: dict)
    enrolled: bool
    def score(self, audio: np.ndarray) -> float       # float32 16 kHz; 0.0 sem cadastro ou sem encoder
    def is_owner(self, audio: np.ndarray) -> bool     # score >= privileged_threshold
    def enroll(self, clips: list[np.ndarray], owner: str) -> None

class Gate:
    def __init__(self, cfg, ctx: Context, speaker: Speaker, audit: Audit,
                 notify: Callable[[str], None], clock: Callable[[], float] = time.monotonic)
    pending: dict | None                               # {"name", "args", "expires"}
    def submit(self, name: str, args: dict) -> str
    def on_user_utterance(self, text: str, audio: np.ndarray) -> None
    def on_click(self, accepted: bool) -> None
    def tick(self) -> None                             # cancela se expirou
```

- Comportamento de `submit`: ferramenta comum roda na hora e devolve o resultado. Ferramenta perigosa não roda: vira `pending`, emite `BUS.emit("confirm", descrição, name=..., args=..., seconds=30)` e devolve `"pendente: peça ao usuário que confirme por voz ou na tela"`. Com outra ação já pendente, devolve `"recusado: já existe uma ação aguardando confirmação"` e mantém a primeira.
- Resolução: ao executar ou cancelar, o `Gate` chama `notify(texto)` com `"Ação confirmada. Resultado: ..."` ou `"Ação cancelada."`, e emite `BUS.emit("confirm_done", ok=...)`. O `notify` é como o resultado chega ao modelo.
- Voz: texto normalizado (minúsculas, sem acento). Negação (`nao`, `cancela`, `cancelar`, `deixa`, `para`) cancela. Afirmação (`sim`, `confirmo`, `confirma`, `pode`, `isso`) executa só se `speaker.is_owner(audio)`; com voz reprovada, a ação continua pendente e emite `BUS.emit("confirm_hint", "Voz não reconhecida. Confirme na tela.")`. Negação tem prioridade sobre afirmação na mesma frase. Outras falas não mudam nada.
- Clique: `on_click(True)` executa sem biometria; `on_click(False)` cancela.
- Cada passo registra em `Audit`.
- Não existe ferramenta registrada que confirme uma ação.

- [ ] **Step 1: Testes** (`tests/test_safety.py`), com `Speaker` falso e relógio falso:

  - "sim" com voz reprovada não executa e mantém `pending`;
  - `on_click(True)` executa mesmo com voz reprovada e sem cadastro;

  - segunda perigosa com uma pendente é recusada e a primeira continua;
  - `"sim"` sem nada pendente não faz nada;
  - nenhuma declaração em `registry.declarations()` tem nome contendo `confirm`.

### Task 5: Áudio

**Files:**
- Create: `viv/audio.py`
- Test: `tests/test_audio.py`

**Interfaces:**
- Produces:

```python
def resolve_input(devices: list[dict], name: str | None) -> int | None   # None = padrão do sistema
def echo_gate(rms: float, playing: bool, headphones: bool, threshold: float) -> bool
def rms(frame: bytes) -> float

class AudioIO:
    FRAME_BYTES = 640                     # 20 ms, 16 kHz, int16
    def __init__(self, cfg: dict)
    input_name: str                       # nome do microfone em uso
    def start(self) -> None               # abre os dois streams uma vez
    def stop(self) -> None                # único lugar que fecha streams
    def read(self, timeout: float = 0.1) -> bytes | None
    def play(self, pcm: bytes) -> None    # 24 kHz int16, enfileira
    def flush(self) -> None               # esvazia a fila de reprodução
    def is_playing(self) -> bool          # True até 300 ms depois do último áudio tocado
    def recent(self, seconds: float = 6.0) -> np.ndarray   # float32 do microfone
    def should_send(self, frame: bytes) -> bool
    def beep(self, kind: str) -> None     # "wake" | "sleep" | "error", tom gerado com numpy
```

- Os streams usam callbacks do `sounddevice`. O callback de saída lê de um buffer de bytes protegido por lock e emite silêncio quando vazio. `flush` só limpa o buffer. Nenhum método além de `stop` chama `close`.

**Interfaces:**

- Produces:

```python
class ClapDetector:
    def __init__(self, min_gap_ms: int = 120, max_gap_ms: int = 700)
    def feed(self, frame: bytes, now: float) -> bool

def matches_name(text: str, aliases: list[str]) -> bool

class NameSpotter:
    def __init__(self, aliases: list[str], transcribe: Callable[[np.ndarray], str], max_seconds: float = 3.0)

def whisper_transcriber(model_name: str) -> Callable[[np.ndarray], str]   # faster-whisper, cpu, int8, language="pt"
```

- `NameSpotter`: recorta por energia; um trecho começa com 3 quadros seguidos acima do piso de ruído e termina com 300 ms de silêncio ou em 3 s; trechos com menos de 300 ms são descartados sem transcrever.

```python
class State(str, Enum):
    SLEEPING = "sleeping"; LISTENING = "listening"; THINKING = "thinking"
    SPEAKING = "speaking"; EXECUTING = "executing"; ERROR = "error"

class Viv:
    def __init__(self, cfg, audio, gate, memory, watcher, connect, gaps=None,
                 clock=time.monotonic)        # connect(config) -> async context manager de sessão
    state: State
    def wake(self, reason: str) -> None       # thread-safe e idempotente
    def sleep(self) -> None                   # thread-safe
    def notify(self, text: str) -> None       # injeta texto na sessão (resultado de confirmação, lembrete)
    async def run(self) -> None               # laço eterno: dorme → acorda → sessão → dorme

def build_config(cfg: dict, memory: Memory) -> dict     # config da sessão Live
def system_instruction(cfg: dict, memory: Memory, now: datetime) -> str   # em viv/persona.py
```
